⚙️ Control Components

🎯 Goal

Make the motor turn ON by completing the control circuit.

Motor will run only if:

  • E-Stop (NC) is OK
  • Overload (NC) is OK
  • Stop Pushbutton (NC) is OK
  • Start Pushbutton (NO) is pressed

Tip: NC means "must be closed / OK". NO means "must be pressed / ON".
