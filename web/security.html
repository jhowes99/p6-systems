Security

Secure Mode: local hardening, password login, CORS restriction, tamper-evident audit.

Secure Mode

When ON: bypass env var is ignored; /hmi requires login; CORS restricted to localhost.

—

Password

Set or change the login password (used when Secure Mode is ON).

Login / Logout

When Secure Mode is ON, log in to access /hmi and API.

Validation exception passcode

Optional. When set, users must enter this passcode to accept a validation finding as an exception (so it no longer counts against the score). Leave empty to allow exceptions without a passcode.

Audit verify

Verify audit log chain (tamper detection).
